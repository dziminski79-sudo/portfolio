# Damian Dev Studio: portfolio site

Personal portfolio for an independent web developer: services, five working
concept projects with problem/solution case studies, tools, process, FAQ, and
contact. All copy lives in `src/lib/content.ts`, so updating projects or
wording never touches layout code.

The projects shown are concept builds, and the site says so on every card.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, deployed on Vercel.

## Run locally

`npm install` then `npm run dev`.
